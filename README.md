
## Типы хранимой информации.
- Логин/пароль.
- Текстовые данные.
- Бинарные данные.
- Банковские карты.

## Режимы работы.
- Локальный (автономный).
- Удалённый.

### Режим - локальный (автономный).
Данные пользователя сохраняются локально. Сервер, используется для хранения резервной копии данных (backUp) и как источник восстановления данных (restore). Для работоспособности, нет необходимости постоянного подключения к серверу. Взаимодействие с данными происходит локально. Подключение к серверу осуществляется только при необходимости выполнения процедур резервного копирования и восстановления. Данные хранятся в зашифрованном виде. 

### Режим - удалённый.
Клиент, представляет собой интерфейс взаимодействия с сервером. Для работоспособности, требуется подключение к серверу. Данные на сервере хранятся в зашифрованном виде. Бинарные данные, шифруются индивидуально. К имени зашифрованного файла, добавляется постфикс `-enc`. Для остальных данных, используется БД. Для хранения резервной копии клиента, используется директория `backUp`. Для хранения файлов - `files`. Директории распологаются в месте нахождения исполняемого файла.

## Общая информация.
- Взаимодействие с сервером осуществляется с использование gRPCS. Необходим сертификат. 
- В случае потери данных (логин, пароль, дополнитеьный секретный ключ), зашифрованные данные считать утраченными. 
- Для защиты данных, используется сторожевой таймер отсутствия активности (10 минут). По истечению времени, пользователю нужно повторно пройти аутентификацию.
