
## Типы хранимой информации.
- логин/пароль;
- текстовые данные;
- бинарные данные;
- банковские карты.

## Режимы работы.
- локальный;
- удалённый.

### Режим - локальный.
Данные пользователя сохраняются локально. Сервер, используется для хранения резервной копии данных (backUp) и как источник восстановления данных (restore). Для работоспособности, нет необходимости подключения к серверу. Все данные хранятся в зашифрованном виде. Для хранения бинарных данных, используется контейнер. Для остальных данных, используется БД.

### Режим - удалённый.
Клиент, представляет собой интерфейс взаимодействия с сервером. Для работоспособности, требуется подключение к серверу. Данные на сервере хранятся в зашифрованном виде. Бинарные данных, шифруются индивидуально. К имени зашифрованного файла, добавляется постфикс `-enc`. Для остальных данных, используется БД.

## Пояснения.
### Флаги.
Режим работы определяется флагом `-m`. 
Возможные значения:
- `local`;
- `remote`.

При отсутствии флага `-m`, режим работы определяется глабальной переменной `MODE_CLIENT`. В случае отсутствия значений `-m` и `MODE_CLIENT`, сервис запускается в режиме - `local`.

### Подключение к серверу.
После запуска сервиса, перейти в раздел - Настройки `Ctrl+D`. 
Указать данные сервера и выполнить проверку связи `Ctrl+N`.
Результат теста отображается изменением цвета текста `Ctrl+N - тест связи`.

### Общая информация.
В клиенте реализован сторожевой таймер активности. Если пользователь, на протяжении десяти минут не проявляет активности, приложение блокируется.
